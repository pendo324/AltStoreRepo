# AltStoreRepo

AltStore and SideStore sources, served with GitHub Pages at
https://pendo324.github.io/AltStoreRepo/.

| Source | URL |
|---|---|
| pendo324 (stable releases of my apps) | https://pendo324.github.io/AltStoreRepo/source.json |
| Phoebus Nightly (builds of Phoebus's `main`) | https://pendo324.github.io/AltStoreRepo/nightly/source.json |

The sources are updated by the publishing workflows of the apps' own
repositories (for Phoebus, `.github/workflows/publish-altstore.yml`), which
add each build and point its download at that repository's releases.
